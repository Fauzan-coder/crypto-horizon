# Security

This project is a read-only public-data dashboard. It stores no user accounts, wallets, exchange keys, or financial records and cannot execute trades. Do not add these credentials to issues or pull requests.

Report security problems through GitHub's private vulnerability reporting when available, rather than posting exploit details publicly. Runtime upstream URLs are fixed; do not add arbitrary user-supplied proxy URLs. Validate data before publishing it and preserve known-good snapshots on failure.
